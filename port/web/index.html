Online (experimental)

2 to 4 players on their own computers, each with their own ROM, in Chrome. Player 1 creates a room and tells the others its code (they type it and press Join room) and drives the menus; the others join with Start on the "press START" page of a multiplayer mode. Connect before pressing Start (reload the page first if the game already runs). The session uses player 1's options and save.

Input recorder

Records everything you press from power-on, with your save (this slot) and your options, into a small file the developers replay automatically to find the first point where a new version plays differently (docs/port/E2E.md). Start recording boots the game again from the start (a running game is restarted). Then play normally: menus, chapter select and gameplay are all recorded. Pausing or switching tabs is fine. Free camera and photo mode are off and the game options are fixed while recording; the game still saves as usual. When you are done, press Stop and save: the file downloads and also stays below.
