# P325 (port-web, 2026-10-26): HUD options "Health always visible" and "Always show cash"

User request (item 5 of the ConkerBFDReloaded comparison): optional HUD options, off by default.

## What the original game does
- **Health** (chocolate pieces, top left): `hud_health_update` (game_BC510.c, every frame from game_frame_end_update in
  single player). D_800D2457 = health shown, D_800CC8BA = real health. A difference adds / drops pieces (sound 0x1A6)
  and sets the show timer D_800D2864 = 240 frames. While it runs, the HUD position D_800D2848 slides to the "shown"
  value D_8009E08A and the timer counts down there; at 0 it slides back to the "hidden" value D_8009E084.
  `hud_draw` draws the pieces only while the position is not "hidden", never in cutscenes (D_800C35EA == 1), on the
  title level 0x1D or in multiplayer (and render_overlay_pass skips hud_draw while D_800BEAC0 / D_800BEAC1).
- **Cash** (player stat 6) is NOT part of the gameplay HUD. It shows:
  1. as a short green "$ N" pop-up 120 units above Conker when an event script gives him cash
     (event_action_object command 4 -> money_collect_popup_spawn; money_popup_draw prints D_800AB634 "$ %d", colour
     0x32,0x7D,0x1C, N = the new total);
  2. on the pause screen (hud_ingame_draw: digit textures, with the front-end health HUD and the lives counter).
  So "on change" is already the original; the option became the 2-way "Always show cash".

## Commits
1. `13891537` "Health always visible" (PORT_OPT_HEALTH_ALWAYS = 2, main.js `healthhud`): in hud_health_update,
   `#ifdef PORT`, keep D_800D2864 at 1 when it would be 0. Turning the option off lets the timer run out (HUD hides).
2. `2c8fd668` "Always show cash" (PORT_OPT_CASH_ALWAYS = 3, main.js `cashhud`): new `hud_cash_always_draw` (PORT only),
   called at the end of hud_health_air_update. Queues the pop-up's own "$ %d" text, same green, flags 0x81 (centred +
   shadow) at (0x10E, 0x14). Skips cutscenes / pause / D_800BEAC1 / level 0x1D. Amount as the pause screen computes it
   (0x7D00 -> 1000000; event 0x5082 without 0x5083 -> scaled by event 0x83 count / 3). Saves and restores the text
   printer globals (colour, position, flags, object anchor D_800CBD78) so other text in the frame is unchanged.

## Pitfall
The text printer's anchor D_800CBD78 (set by text_set_box for object-anchored pop-ups) stays set until the text queue
is drawn; a screen-space print in the same frame must clear it, or it is attached to the object.
