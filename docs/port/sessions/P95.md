## 2. func_15035220 (game_eu_62360.c, NM, hand-written)

Builds the mirrored joint matrices of one draw-queue entry and its alpha. Modes 0 / 1: reflection in y = b
(`src * diag(1,-1,1,1)`, `dst.y = 2b - src.y`), fade by the height y - b; mode 2: reflection about the vertical plane
through (a, b, c) turned by f around y (rotate -f, flip x, rotate f), fade by the 2D distance func_150ADE40; other modes
return at once. Source matrices are Mtx (guMtxL2F) when `fixed`, else f32 with the last column reset in place; the
output is converted to Mtx in place when `tofixed`. Alpha: 0 beyond h, full below g (mode 0: ramp over 10 units),
linear between. Objects with unk9C get func_15034A18 with unk1D4 swapped to the new matrices. The f32 -> u8 alpha
conversions use `IDO_F2U8` (IDO's cvt gives 0xFF for values <= -1, e.g. mode 0 below the plane; plain `(u32)` of a
negative float is undefined and traps on wasm).

Verification: `p95/gen5220.py` -> `s5220.txt`, 30 setups EQUIV (`port_work/p95/k5220b.log`); mutants 23/23 killed
(`muts_5220.txt`, `muts_5220b.txt`; `mut_5220b.log`, `mut_5220c.log`). The flip / rotation matrices only reach stubbed
callees by stack pointer, so their contents (flip[1][1] / flip[0][0], func_150A7A48 operand order) are not testable
here: UNVERIFIED.
