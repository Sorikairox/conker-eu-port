## func_1508F9F4: the uninitialised spawn flag (decision)
- The asm never sets its spawn flag (sp+0x44) to non-zero: it clears it when unkB2 < 0x5B or the pop delay is 0
  and otherwise uses whatever the stack slot holds. The delay (s7) is stack garbage only when unkB2 < 0x5B, where
  the flag is 0, so it is never used.
- Trace (EU matching ELF): func_1508F9F4 is called only from func_1508F0A4 (jal at 0x1508F514; no data reference),
  which is called only from func_15019414 (0x150193FC), called only from func_1501878C (0x15018B10).
  Let P = func_15019414's sp: func_1508F0A4's sp = P - 0x18, func_1508F9F4's sp = P - 0x68, the slot = P - 0x24.
  Before func_1508F0A4, func_15019414 always calls func_1517ABB0 (frame 0x40, sp = P - 0x40), whose prologue does
  `sw s1, 0x1C(sp)` = P - 0x24. func_1508F0D4 (frame 0x48, called by func_1508F0A4 just before) never writes
  sp+0x3C (= the slot) and its callees' frames lie below it. func_15019414 does not touch s1, and
  func_1501878C's s1 at that call is `lui s1, 0x800C; addiu s1, -0x1210` = 0x800BEDF0 (its display list pointer
  address), set before the first frame call and never changed. So on the N64 the flag word is always 0x800BEDF0:
  **spawning is enabled whenever the asm does not clear it**. C: `spawn = (delay != 0)` for unkB2 >= 0x5B, else 0;
  delay = 0 when unused. Comment in the code.
- Verified against the asm with the slot preset to 0x800BEDF0: the stack of the harness is zero-filled and
  premapped, so DIFFTEST_POKE cannot reach it; `port_work/p129/difftest_stk.py` is a test copy of difftest.py (diff: `p129/difftest_stkfill.patch`; wrapper
  `p129/dts.sh`, which expects the copy in port_work/p129) with
  `DIFFTEST_STKFILL=8067FEF4=800BEDF0` (SP_ENTRY 0x8067FF00 - 0x50 + 0x44). Without it the reference never spawns
  (slot 0) and the C differs (trial 85: func_150ADA20 called by the C only), as expected.
- Equivalent mutants: timer clamp `< 0` -> `< 1`; unkB2 as s16 (negative -> no spawn, >= 0x8000 -> delay 0 -> no
