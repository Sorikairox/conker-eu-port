## What it does
Per-frame update of the ambient flyers (birds / bats) func_15175900 spawns: removal when the type row
(D_800DDE80, 0x14 bytes) or D_800DDF78[type] is off; the level-6 scatter event (types 8 / 9, D_800BE9F0 == 6,
D_800C35EA, D_800C3A08 == 0xF, after 60 frames of D_800C39D0) switches them to circling (flag 0x200) round
(-3478, 3858) with a shrinking radius while they sink, removed below -3100 or when the event ends; alpha fade in / out;
the looping sound follows the flyer; flag 4 tethers to home (turn back beyond rangeMax / away inside rangeMin with
flag 0x10, state 3 turns to targetHeading, state 2 wanders with random headings); flag 0x80 follows the floor; flag
0x40 bobs in height; then pitch / heading / roll / speed integration against the D_8008D450 limits (0x38 bytes per
type), wing model swap by pitch (flag 1 = fixed), chirp for kind 0x13, removal outside both views (flag 2).
The C uses local struct types (Flyer / FlyerType / FlyerModels) whose offsets follow the asm.
