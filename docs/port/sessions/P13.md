## difftest changes (selftest 20/20 after all of them)

- `call_site_writes`: the scan now stops at the delay slot of an earlier branch or jump. The old check tested the same word
  twice, so a previous `jal`'s delay slot (`a2 = 3`) widened a 1-arg call to 3 args. That gave a false DIFFER in func_15007B3C.
- An unnamed callee (`0x1509xxxx`, an EU address with no symbol) now takes its arity from the TU prototype `func_<ADDR>`.
- Leading `f32`/`f64` parameters (f12/f14 under o32) mark their a-register slots as junk. They are no longer compared.
  This was a false DIFFER on `func_15095A4C(f32, f32, ...)` a0.
- New opt-in `DIFFTEST_RET="ADDR=VAL,..."`: the stub at ADDR returns VAL in v0 on both sides (reach code behind
  `if (f() != 0) return`). Passed through `tools/port/difftest.sh`.
- Bounded runs: macOS has no `timeout`, so I ran difftest through `docker exec ... timeout -s KILL N python3 ...`
  (a 10-line wrapper in the session scratchpad). Worth adding to `tools/port/difftest.sh` as `DIFFTEST_TIMEOUT`.
