### tablesig.py v2 (`p162/tablesig.py`)
- D_ names resolve to EU addresses through `undefined_syms.eu.txt` (US names such as D_80082FA4 live elsewhere).
- Each jalr is tied to its table (register trace: `lw $t9, %lo(SYM)(..)` or `lw $t9, off(base)` with base from
  `%hi/%lo(SYM)` through addu / or / addiu), and only those jalrs are tested; v0 **and f0** reads count; `mtc1 x, $f0`
  is a write.
- Tables start at the run start and at every named address inside a run (a single named entry counts: D_80089EB8);
  leading NULL entries are skipped when naming (D_80082BFC). "maybe:" = void entries past the next named address
  (the dispatcher's real extent is unknown).
- Result: 334 tables, the P159-class definite list is now D_8008B734 (fixed), D_8008FFD0 (fixed), D_8008FC30 and
  D_8008FC58 (1C3530). "maybe" rows: D_80089BA4, D_80089E40, D_80089EB8, D_80089EBC, D_80089EFC, D_80089F0C,
  D_8008B730, D_8008FC10, D_8008FF30, D_80090070, D_800900D0 (check the index range of each dispatcher by hand).
