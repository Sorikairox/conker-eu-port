## Coordinator item: literal N64 address in the translated walls

`D5E90_walls.inc` had `at = 0x800A0000; F[8].u = LW(at + -1360);` (the raw `.word` block at func_150AACF4 that splat
left undisassembled; asm2c_hand.py's decode_word gave a plain `lui`). **Fixed in the generator**:
`tools/port/asm2c_hand.py` `reloc_data()` turns a `lui r, 0x80xx` (RDRAM) whose register is then used as a base in
the same straight-line run into `%hi(D_X)` / `%lo(D_X)`, so the C reads `HI((u32) &D_8009FAB0)` +
`LO((u32) &D_8009FAB0)` (it refuses a lui that serves two addresses). Regenerated with `gen_d5e90_walls.sh`: only
those two lines changed; `D5E90_ray.inc` unchanged; `nmasm_walls.py` 300 trials 0 diffs. D5E90_anim.c / D5E90.c /
the new D5E90_mtx.c are hand C with symbols only (the only literal is the ASM2C_TRACE debug ring, off by default).
