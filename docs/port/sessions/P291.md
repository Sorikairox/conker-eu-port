## Task 1: func_150FBA40 star_field_draw (game_eu_129250, Rare hand asm, from group D)

Readable NM C (registry row `P291`, HARNESS= / HMUT=): 8000 stars of D_800DC2B0 (s16 upper halves of f32 x / y / z,
u8 tint, u8 alpha), rotated by the view matrix (w = third column, no translation), skipped when w <= 203 or the
projection is outside the player's viewport (D_800BE628[D_80082FA4]), else 4 one-pixel G_FILLRECTs with bilinear
alpha (prim colour = tint | rint(alpha * weight)). The list is padded to 16 bytes before / after and written through
KSEG1 (`STAR_UNCACHED`, identity under PORT); returns the cached end.
- difftest cannot run the reference (64-bit dsll32 / daddu / sd: Unicorn MIPS32 faults), and the first C draft used
  u64 commands, which IDO compiles to `__ll_lshift` (64-bit libultra code, faults in Unicorn too). The C writes the
  two 32-bit words per command instead (port-safe as well). The asm's 64-bit rectangle steps (daddu of 0x4000 / 4
  to both halves) and the sign extension of the ORed words only differ for x or y >= 2^17 pixels: documented, not
  modelled.
- New harness tools/port/difftest/nmasm_stars.py (Ref = nmasm_vis5858's VR4300 interpreter; it gained mult / mflo /
  mfhi / add / daddu / dsubu / div.s, and Cand loads .init for IDO's __ll helpers): random rotations and exact
  axis-aligned views (w == 203, .5 fractions for ties, points exactly on all four viewport edges), players 0..3,
  aligned / unaligned / KSEG1 list pointers. 300 trials x seeds 1-3 EQUIV (stars_s*.log, ~290k stars drawn each).
- Mutants: 17/18 killed (hmut_stars.log, 40 trials). Survivor `if (0)` instead of the end padding: equivalent, the list
  start is aligned to 16 and every star adds 64 bytes, so the end is always aligned.
