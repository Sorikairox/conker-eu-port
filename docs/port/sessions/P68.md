## Harness notes (important for the next sessions)

- **Knob addresses are EU addresses.** The symbol names are US-style: `func_15048A70` is at 0x15048D60 in EU,
  `func_1502B5C8` at 0x1502B8B8, `D_800D154C` at 0x800D196C, `D_800BE9F0` at 0x800BEE10 ... A RET / RETF / OUTW knob
  on the name's number silently does nothing (the stub returns random values). Look up with
  `port_work/p68_sym.sh SYM...` (mips nm of `build/conker.eu.elf`). Undefined-symbol data (D_800E1004 ...) do sit at
  their name. P68's first runs had this wrong; all setups were regenerated and re-run with EU addresses.
- **OUTW writes a word**: for a u16 out-param (func_10011EB8's volume in func_1506BF5C) it also overwrote the next
  stack slot of the candidate (a saved register) and gave a false DIFFER. Use DIFFTEST_OUTB with 2 bytes.
- An IDO `switch` jump table in a candidate faulted at 0 in a random trial (D_800D154C = NULL, page-0 reads, the
  P18 Unicorn alias bug); func_1506BF5C uses if-chains. Seeds 1 / 2 of the random run still show this NULL-object
  artifact for func_1506BF5C (ref reads page 0, candidate faults); all setups with a real object are EQUIV.
- `docs/port/sessions/p68/mut.sh` runs 100 random trials first and stops at the first DIFFER (p67/mut.sh ran every
  setup for every mutant: hours for 300+ setups). Setups whose names are not listed run all.
- Float arguments in f12 / f14 are not part of the callee trace: func_1512C77C's `- 180.0f` mutant survives until
  the value is read back through DIFFTEST_ARGMEM on func_15048758 (EU 0x15048A48).
