### difftest harness fix (test the harness)

The first knob / mutant runs of func_1506EF5C / func_1507488C were EQUIV with **every mutant LIVE**: the candidate was
silently dropped. build_tu only recognised `#else` immediately followed by the pragma; game_981E0.c keeps note lines

old NM C (the function under test). Fixed in `tools/port/difftest/difftest.py`: comment / blank lines may sit between
`#else` and the pragma, and build_tu now raises when the candidate's (NM-resolved) definition is not in the spliced
TU. Selftest case `cases/func_1506EF5C.c` (EQUIV + a DIFFER mutant). All P80 results are from after the fix
(func_150322B8's ref 1148 / cand 597 words, so it was never affected).
