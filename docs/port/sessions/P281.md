## Harness changes (tools/port/difftest)

- `DIFFTEST_STOPCALL=ADDR=N`: the N-th call of the stub at ADDR ends the trial ("stopped"): call lists, call counts
  and written memory are compared, registers / return value are not; one side stopped alone = DIFFER. This is the
  way to test endless thread loops (viMgrMain, game_main, prenmi_thread's final `while (1)`). No knob = old.
- `DIFFTEST_RETV1=ADDR=V1;V2..`: low word (v1) of a stub's u64 return (osGetTime busy waits). reverify.sh setup
  files take it as an optional 9th field.
- Struct-by-value return (`ldiv_t ldiv(long, long)`): the hidden result pointer is a0, so the arity now counts it;
  before, ldiv's divisor (a2) was never compared (`DIFFTEST_SRET_OLD=1` = old).
- ldiv's stub computes the real quotient / remainder through a0 (`DIFFTEST_LDIV_OLD=1` = old random), so digit loops
  produce real digits.
- selftest: 10 new cases (func_100052A0 STOPCALL / RETV1, func_10001550 SRET / LDIV); cases in
  tools/port/difftest/cases. Result: 140 ok, 0 failed.
