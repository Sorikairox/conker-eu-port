# P322 (port-web, 2026-10-26): scripted function renames (rename.py + names.tsv), first 3 renames

User request: a function a session touches or reads gets an explicit readable name, with its original asm name kept
in a comment. Approved: build a rename script and apply it to the three cutscene-skip functions first.

## Tool (`tools/eu_port/rename.py`, table `tools/eu_port/names.tsv`, workflow `docs/RENAMING.md`)
- names.tsv (`old<TAB>new<TAB>description`) is the source of truth; `--check` = dry run (every file/line, symbol
  addition, comment site, file moves), no flag = apply (rows already applied are skipped), `--verify` = no old name
  left in scope + verify_all (clean re-split) + NM link.
- How splat names functions: names in `symbol_addrs.eu.txt` (US names mapped to EU addresses, plus real names);
  anything unlisted is `func_<EU vram>`. So a rename adds `new = 0x<EU addr>; // type:func` (address from
  conker/build/conker.eu.map, `// was old: desc` line above; splat skips `//` lines) or renames the listed entry in
  place. The re-split then gives the asm file, glabel, jal and data refs the new name (asm/ and *_auto.txt are
  generated, untracked).
- Text replacement: whole words, also `_name` (EXPORTED_FUNCTIONS), `__wrap_/__real_name` (--wrap); never inside
  `was name`. Scope: tracked files in conker/src_eu, conker/include, EU symbol/undefined lists, conker/Makefile,
  conker.eu.yaml, port/, tools/ (registries, selftest cases) + the setup/mutant files verify_registry.tsv points at.
  Left alone: conker/src (US), *.md, docs/, *.log, port_work/, repair_log.tsv, tools/port/pilot/, vendored tools.
- Files whose path holds the old name are git mv'ed (selftest cases `cases/func_X.c` are found by name).
- `/* was old */` goes above the C definition in src_eu (above the GLOBAL_ASM pragma if there is no C).
- Guards: refuses without the right CONKER_ROOT; stops if the new name is already used for something else or the
  address already has another name; warns when a shared conker/include header changes while the US source uses
  the old name.
- difftest knobs are keyed by EU addresses (jal words), so no knob changes; registry `func` rows are renamed as text.
- Dry-run tests (not applied): func_10001420 (US name listed in the symbol file: renamed in place),
  func_10001194 (selftest case moved, selftest.sh / registry / mutant file renamed), func_1501D348 (port/Makefile
  --wrap and `__wrap_/__real_` in p103_boot.c renamed), a collision row (refused).

## Limits
- Other branches (port, port-b, eu) still use the old names; after merging, re-run `rename.py` so new uses are renamed.
  Edits near the renamed lines will conflict textually.
- Several tools only recognise `func_[0-9A-F]{8}` (n64mem.py, stubcalls.py, m2c_sanity.py, bootpath.py, difftest
  def_intfirst / size fallback); renamed functions may drop out of their call lists.
