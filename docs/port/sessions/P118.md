## 1. Method

Run (host, worktree root): `eval "$(tools/eu_port/wt.sh env web)"; python3 port/tools/m2c_sanity.py [--func F] [--top N]`
(~10 s; needs Homebrew LLVM `opt` at /opt/homebrew/opt/llvm/bin/opt).

- Scope: functions defined inside `#ifdef NON_MATCHING` branches of conker/src_eu (1098; 1053 scanned, 45 have no
  symbol of that name in the EU ELF).
- IR: `port/build/ll/<tu>.c.ll` (-O0, no optnone) run through `opt -passes=sroa,instcombine<no-verify-fixpoint>`
  (cache `port/build/m2c_sanity/`): locals become SSA, constant GEPs become byte offsets. Raw -O0 IR for the scaled
  check (the GEP element type is still the C pointer type).
- asm: `port/build/arity/eu_elf.dis` + `eu_elf.sym` (arity_scan.py's cache of the EU ELF). Per-function linear pass:
  lui/addiu/addu constant tracking (globals), a0..a3 entry tracking, sp-derived registers (stack), a linear
  multiplier tracker (sll/addu/subu chains, mult by li) and self-increments `addiu r,r,C`.
- Each memory access gets a location: `G:addr` (global, `+` = variable index), `A<i>:off` (entry argument),
  `O:off` (any other base, pooled). Stack accesses and loads copied straight to the stack (aggregate copies) are dropped.

Kinds (TSV columns function, file, kind, conf, path, detail):
- `width`: at one location one side uses a size (b/h/w/d) the other lacks while having another size there.
  high for G/A locations with disjoint size sets; pooled O rows high only when the asm loads a narrow size there,
  the IR loads only wider values there and the IR has fewer narrow loads overall (func_150337A8's shape); 8-vs-4 = low.
- `stride`: IR `phi ptr` fed by `gep p, C` whose byte step C is not an asm self-increment step (unrolled loops are
  accepted when the IR also addresses the intermediate elements). high if C = 2/4/8 x an asm step. Index-loop steps
  (`idx`) are low (IDO index/unroll forms make them noisy).
- `scaled`: -O0 GEP of element size k>1 indexed by `mul x, K` / `shl`, with the m2c byte idiom `(x * K) + &SYM` in
  the source. high when the asm builds x*K but not x*K*k; dropped when the asm builds x*K*k (C is right).
- `sign`: lb/lbu vs IR sext/zext at the same location and size (low).
- `path`: 2 = named in the P113/P116 runtime logs/notes (port_work/p113, port_work/p116, P113.md, P116.md),
  1 = direct C caller/callee of such a function, 0 = other.
- Rank: conf, then path, pooled-O width rows half a level below the located rows.
