- sort the vertices by z (A lowest, C highest), x on edge A-C and on A-B or B-C at z (24.8, `mult` wraps, `div`
  by zero gives the VR4300 quotient), accept if x lies between them, widened by 1 on each side;

- entry n of D_800D3720: +0 height, +4 pointer to the triangle's 3 vertex offsets, +8 vertex base, +0xC tag. The
  count stops at 0x27 (later hits overwrite entry 0x27).
