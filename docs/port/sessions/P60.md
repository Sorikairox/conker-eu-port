## 1. Notes per function

- **func_1505E0C4** (why Conker stayed in the bind pose: this fills anim +0x40 with the animation header and sets
  +0x28 / +0x18). Keeps `s32` (both callers declare it so; returns 0, the asm leaves scratch, no caller reads it);
  the tests use `p60/t_1505E0C4.c` (same body, `void`). Arguments: (obj, entry, anim, unused, restart, id, set,
  speed, blend, frame, loop_start, hold). `set` is replaced by obj +6 when there is an object; the file id is
  `entry[0]` or `2 * id` (s32, not masked). When the header lookup returns NULL the asm reads stack leftovers for
  data / size; the C uses 0 (= func_1505DFDC, no animation). The `id == 0xFFFF` restart test is redundant
  (id == anim +4 & 0x7FFF can never be 0xFFFF): the surviving mutant is equivalent.
  structs.h: struct_eu_anim gets `unk0` (callback), `unk3A` / `unk3C` (blend step / countdown); struct126 gets
  `unk5A` (s16).
- **func_1507F640**: `void (void)`. game_981E0.c called it with one argument (`func_1507F640(temp_a0)`, implicit
  int): under NM it now calls `func_1507F640()` with a hoisted prototype. The fallback idle 0x25 (ctl +0x1A) is
  unreachable (ctl +0x1A != 0 already picked 0x63 and returned) unless func_1507F834 / func_1507F3B0 change the
  record: the mutant survives. Jump table jtbl_8009BFCC dumped with `port_work/p60_jt.py`.
  structs.h: struct126 `unk32` (u16), `unk5C` / `unk5D`, `pad1AC` + `unk1B2` (struct126 was 0x1AC long; no
  by-value / array users). +0x17 / +0x1A stay `pad17[0]` / `pad17[3]` (matching code uses `pad17[]`).
- **func_15051558**: `void` under NM (prototype in game_eu_78230.c's NM block). The m2c draft was wrong in:
  func_1510FDA0 has 7 args (not 8); `D_800CC3C8[n * 0x32C]` is a byte = `D_800CC2D0[n - 1].id` (rec +0x274 =
  carrier + 1); the file has no prototype of func_1505A250 before the body (implicit -> double args: needs one).
