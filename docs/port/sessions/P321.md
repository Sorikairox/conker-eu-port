# P321 (port-web, 2026-10-26): hold L for 3 s to skip a cutscene (port build only)

User request: L must not skip at once; show a 3 s loading ring around an L badge at the bottom right and skip
only when L is held for 3 s straight.

- Game C, `func_1501E0C8` (game_eu_4A070.c) under `#ifdef PORT`: the L test moves to the end. Once the scene may
  be skipped, each `return 1` becomes `SKIP_YES` = `port_skip_hold()`. Without PORT `SKIP_YES` is 1, and the L test
  stays first, so the NON_MATCHING game is unchanged.
- `port_skip_hold` (port/ultra/pc_os.c) counts retraces while L is held: 150 (PAL) = 3 s. It counts frames, not the
  clock, so ?det runs don't change. Gaps over 25 retraces restart it. `port_skip_progress()` (exported) gives 0..1.
- L comes from `port_pad0_held` (pc_pif.c): pad 0 buttons as delivered at the last controller read. Two things
  that don't work: the game's `D_800BEB30` is edge-triggered (one frame per press), and `port_pads` is
  overwritten by the page every animation frame, so it misses ?padf.
- Page: `#skipring` SVG (index.html) in #screen, bottom right; main.js pollInput sets the arc from
  `_port_skip_progress`. SVG has no `.hidden` property: use toggleAttribute.
- Build gotcha: game TUs are only recompiled after `port/web/run.sh census` (vbe.stamp depends on files.tsv, not
  on src_eu); a bare `run.sh build` kept the P320 object.
