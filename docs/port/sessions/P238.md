## 3. Harness: DIFFTEST_OUTP (new knob)
- `DIFFTEST_OUTP="ADDR=N.I:W0;W1;...,..."` (hex ADDR / W, decimal N / I): at every call to ADDR the stub reads the
  pointer at word I of the array that argument N points to (aN[I]; N >= 4 = stack argument) and writes the words
  there through `stub_write` (so they enter the compared write log like OUTA). Several `N.I:W...` per ADDR are
  separated by `/`. It closes the P237 hole: func_15145EA4 writes its transformed points through `dst[i]`, which no
  other knob could reach. New knob only (no `_OLD` switch needed: without the env var nothing changes). Also listed
  in the `[knob callee never called]` note and passed through `tools/port/difftest.sh`.
- Selftest: 3 new cases on func_15160E30 (case draft `tools/port/difftest/cases/func_15160E30.c` = the P237
  candidate): as is with OUTP = EQUIV, the swapped subtraction `dir[0] = start[0] - dir[0]` with OUTP = DIFFER (argument
  memory of func_15145128), the same mutant without OUTP = EQUIV (documents the hole). Selftest before 100 / 100,
  after 103 / 103.
- Example for func_15160E30: `DIFFTEST_OUTP=15146414=1.0:41200000;41A00000;41F00000/1.1:42200000;C1200000;42480000`.
