## 1. Why P118 missed func_15022440

`game_eu_4A070.c:2447` `func_15082E44((sp38 * 0x30) + D_800D20FC, ...)` with `extern struct258 *D_800D20FC`
(sizeof 0x10). -O0 IR: `%96 = mul i32 %95, 48; %97 = load ptr, ptr @D_800D20FC; gep %struct.struct258, ptr %97, i32 %96`.
P118's `scaled` kind only accepted a GEP whose base is the array symbol itself (`@SYM`) plus a source-regex idiom
`(x*K) + &SYM`. Here the base is a pointer **loaded** from the variable, the source has no `&`, so no row.
The asm (`sll t2,a1,2; subu t2,t2,a1; sll t2,t2,4; lw t3,%lo(D_800D20FC)(t3); addu a0,t2,t3` in the jal delay slot)
adds a1*0x30 bytes.

## 2. Method change

New per-base comparison (kinds `pscale`, `pindex`), keyed by where the pointer comes from:

| key | IR (raw -O0) | asm |
|---|---|---|
| `G:addr` pointer variable | `load ptr, ptr @SYM` (or a const GEP of it) | `lw r, %lo(SYM)(lui)` |
| `GI:addr` pointer table entry | `load ptr, ptr gep(@SYM, i)` | `lw r, off(lui+idx)` |
| `A:i` argument | load of the parameter's alloca | a0..a3 (moves, sp spills followed) |
| `F:base+off` pointer field | `load ptr` of a const GEP of a keyed pointer | `lw r, off(keyed reg)` |
| `GA:addr` `&SYM[i]` in a local | GEP of `@SYM` with a variable index | lui+addu index (`g` state) |

- m2c temp locals are looked through: an alloca whose every store puts a pointer of one key in it gets that key
  (`temp_s0 = &D_800CC2D0[arg1]; ... temp_s0 + (arg2 * 4)`).
- IR candidates: single-index GEP, element size S > 1, non-constant index; K = multiplier of the index (`mul x, K`,
  `shl x, c`, looking through sext/zext, `+ const`, and `x*K + y`), else 1. Effective byte scale E = S*K.
- asm: at every `addu r, base, idx` where `base` holds a keyed pointer, the linear tracker's coefficient of `idx` is
  recorded for that key (pidx). Two tracker fixes needed for the target: **jal delay slots are now processed before
  the jal** (the `addu a0,t2,t3` was evaluated after the call had cleared t2/t3), and pointer values spilled to sp
  slots are restored on reload.
- `pscale` high: the asm adds x*K to that same base and never x*K*S (the m2c byte idiom on a typed pointer).
  Unknown base (call return etc.): med only when the function's asm has K but no K*S anywhere and the source line
  is found; nothing emitted otherwise. Array-symbol bases stay in P118's `scaled`.
- `pindex` (plain `p[i]`): asm multipliers on that base exclude S: high if S occurs nowhere in the asm and there
  is one multiplier, else med. Bodies written over hand asm (nm_asm/, "Handwritten" / "in assembly" comment) -> low.
- `spaddr` (P124 idea, folded in cheaply, low): asm passes `addiu aN,sp,OFF` to a jal and the next stack slot above
  OFF (<= 8 bytes, no other passed slot between) is store-only; IR passes the address of a scalar alloca and has
  store-only allocas. The callee's read size is not checked.
- detail column starts with `L<line>` (best effort, `/`-joined when several lines match).
- `--stats` prints per-candidate STAT lines; `--func` now writes `port/build/m2c_sanity/func.tsv` instead of
  overwriting the TSV.

Candidate coverage (`--stats`): 390 IR GEPs; asm evidence on the same base for 243 (hit = C agrees: 213);
G 101, GI 105, A 103, F 9, GA 1, unknown base with K>1 71 (all silent: no K-only asm evidence).
