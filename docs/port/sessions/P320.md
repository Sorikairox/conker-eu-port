# P320 (port-web, 2026-10-26): cutscenes skippable from the first viewing (port build only)

User request: make cutscenes skippable by default (the original allows it only after a scene was seen once).

## Where the game decides (game_eu_4A070.c)
- `func_1501E220(slot)` (called every frame by `func_1501E46C` from the main loop `func_15019130`): when a scene
  plays and `func_1501E0C8` says yes (and >= 0x4C frames are left) it fades out 0x19 frames and ends the scene with
  `func_1501DF70` (which runs the rest of the script, `func_1501DE84`).
- `func_1501E0C8(slot)` = the skip test. Skip button is **L (0x20)**, newly pressed (`D_800BEB30`; keyboard key R in
  the web build). Rules:
  - level 0x21 (boot intro): Start (0x1000) and `D_8000030C` (osResetType) == 1 and frame >= 251, i.e. only after a reset;
  - level 0x1D (title / attract): only after a pending menu request `D_80090124` or scene 5 (not a seen gate; unchanged);
  - other levels: L, `D_800C40BC == 0` (the scene has no "no skip" event 0xE, func_1501DB18 / func_1509C850 case 6),
    then `D_800D3260`, or `func_1501D330(level, scene)` (seen) and (forced `D_800C40B9` or > 25 frames left).
- `func_1501D330(level, scene)` = seen query: bit `scene` of `D_800C3A60[level]` (u64 per level, packed into the
  EEPROM save by game_33990.c) or `D_800C3670`. `func_1501D2C4` sets the bit when a scene ends.

## Change (all `#ifdef PORT`; default eu and NON_MATCHING builds unchanged, verify_all OK, NM links)
1. `func_1501D330` returns 1 under PORT (every scene counts as seen). Nothing is written; the real seen bits are
   still recorded and saved exactly as before.
2. `func_1501E0C8` level 0x21: the `D_8000030C == 1` term is dropped under PORT (boot intro skippable with Start on a
   cold boot).
3. `func_1501E0C8`: the `D_800C40BC` "no skip" marker is ignored under PORT. Needed for the user's case: the opening
   (level 0x18 scene 1) carries this marker (runtime log: c4bc 1 at every L press), so on the N64 it can never be
   skipped. Risk: other marked scenes become skippable too; skipping runs the game's own end-of-scene path.
Each site has a "DELIBERATE PORT CHANGE (P320)" comment.

Pitfall found on the way: game-C debug logging must use `port_glog` (the format string is in byte-swapped vbe
memory); `port_log` from a game TU prints nothing.
