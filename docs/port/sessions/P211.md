## 3. Rail script runner: what happens to a command's return value (rule)
- func_1509E3D4 (rail_script_command) is entry 14 of D_80088874 (EU 0x80088874, 15 handlers; D_80088838 is the
  sibling table). Two dispatchers reach it, both pass the handler's v0 straight back to their caller:
  - the event VM natives 5 / 6 (hand asm tail in func_150ADFD0 at 150AE60C: `jalr v1; ...; jr ra`, v0 untouched).
    The VM stores the native's result in the result register D_800D3C68 (operand mode 5); it is only seen when a
    later script instruction reads mode 5 before the next native call overwrites it (return / `return value` /
    script calls keep or replace it);
  - func_1509BFB0 (EU 1509C3C0, varargs `(n, word, ...)`, index = (word >> 12) - 1): v0 returned to the C caller.
- Who reads it for the rail commands (id nibble 0xF):
  - Event scripts: `p211/railcmds.py baserom.eu.z64` walks every event block (p106 loader), finds each native-6
    call with an id 0xFxxx, takes the pushed command number and follows the script (jumps both ways, returns into
    every script caller) until mode 5 is read or the next call / return-from-entry. 83 rail calls: the result is
    read only after commands **3** (2 calls, returns 0), **6** (func_1508AB7C, 7 calls), **22** (1 of 2) and
    **25** (eased value, 1 call). Commands 1, 2, 4, 5, 7, 10-15, 17-21, 23, 24: never read.
  - C callers of func_1509BFB0 / func_1509BE40: `p211/runner_sites.py` (71 + 106 sites): no site passes a 0xFxxx
    word (constants 0x2xxx-0x9xxx; the two loaded from memory / v0|0x2000 are other tables).
- **Rule**: a rail command's C must return the asm's exact value when the command is 3, 6, 22 or 25. For the other
  commands the value is never consumed: return the asm's value where it is defined (0, a band, a pointer...) and a
  defined value (0) where the asm leaves a callee's scratch v0 (e.g. func_150ADA68's leftover); pin that callee's
  v0 with DIFFTEST_RET in difftest so the compare still covers every other path. (func_1508DE78 from P209 returns
  the asm's pointer value; harmless, command 10 is never read.)
