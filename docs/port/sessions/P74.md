- **POKE does not reach ROM-mapped data**: difftest maps code / rodata from the ROM image (and `.data` on odd trials),

  the ROM counts (27 / 31 / 45 for kinds 0..2) and D_80082FA0 (0x80083330, `.data`) / the D_800847E4 / D_800847C0..D8

  VRAM 0x80082EB0). Written as literals.
