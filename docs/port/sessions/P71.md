### difftest: callee arity from declarations (P70's func_15030448 blocker)

inside the macro call), overriding the 2-argument declaration, so the scratch a2 was compared. Now declarations
(a type before the name, `_is_decl`) win over call statements, and lists are split only at top-level commas
