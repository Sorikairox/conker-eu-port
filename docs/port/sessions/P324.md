## Pitfall (skip intro)
A level / menu request on the first frame of a freshly started level stops the game: the main thread stays blocked on
the main-loop queue D_800BEE30 (`?dump=` thread list), no gfx frames. Seen twice: menu request on boot frame 1, and on
the first frame of level 0x21. Waiting 25 boot-screen frames and 32 mode-1 frames fixes it (title at retrace 71).
Not investigated further (the original never does this).
