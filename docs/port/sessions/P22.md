**Mechanism (Makefile, NON_MATCHING=1 only):** `src_eu/nm_asm/X.c` holds C for functions of `asm/X.s` (whole file
`#ifdef NON_MATCHING`). `SRC_DIRS += src_eu/nm_asm` only in NM builds; the NM ld script gets
`build_nm/src_eu/nm_asm/X.c.o(.text)` right after `build_nm/asm/X.s.o(.text)` and its `.rodata` in `.nm_rodata`;
`build_nm/asm/X.s.o` is assembled and then `objcopy --weaken-symbol=` for every name in `NM_ASM_C_FUNCS_X`, so the C
definition wins at link time. To add a function: write it in `src_eu/nm_asm/D5E90.c` and append its name to
`NM_ASM_C_FUNCS_D5E90`. The ld script is only regenerated when missing: `rm build_nm/conker.ld` after changing the rule.
Symbols the C needs that have no declaration go to `undefined_syms.eu.txt` (D_8009FAB0 added).
