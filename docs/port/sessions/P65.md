## Notes / gotchas

- **DIFFTEST_RET / ARGMEM keys are EU addresses** of the callee, not the US-style name: func_15083E90 is called at
  0x150842F8 (compute `(jal_word & 0x3FFFFFF) << 2 | 0x10000000`). With the US address the stub returned random
  values and half the trials faulted.
- Heap page 0x80500000 is in the Unicorn TLB alias slot ((addr >> 12) & 0xFF == 0): do not put setup records there.
- Stubbed callees do not read memory, so stack matrices (normalisation in func_15030758) are only compared with
  `DIFFTEST_ARGMEM="150A7C70=0:64,150A7F28=0:64,150A7F28=1:64"` (guMtxF2L, func_150A7A48).
- **func_15036FD8**: jump table jtbl_80098604 is .late_rodata (ids 0x75..0xB4 that skip the first call of a frame).
- **func_15030758**: in pass 0 only records without +0x1E; pass 1 (only if one was seen) the sub-model ones. A
  record with a target and no matrix buffer stores the joint matrix pointer into target +0x3E0[buf]; for a
  sub-model that is a pointer to the function's *stack* matrix (as the asm does: dangling after return).
  Callbacks: **D_80084550 is a data table of code pointers** (indexed by record +7); the browser must map them.
- **func_150028BC**: the vertex-slot buffer is 32 words on the stack (indices >= 32 would overrun in both).
  The DL loop count is the constant 1 (only D_800C48A8[id][0]).
- **func_1503AB20**: mode 3's "no joint" test compares the u16 +0x278 with -1, which never matches (kept as
  `!= -1`); mode 1 uses an unsigned `% 20` of func_150ADA20 (s32 in functions.h, cast). The struct127 field types
  for +0x276..+0x287 do not match the asm (u8 mode, u16 phase / timer, s8 offsets): accessed through LOOK_* macros.
- **func_150A69E0**: its .s also has an unreferenced second entry at 0x150A6A18 (no symbol, no caller); not
  translated.
