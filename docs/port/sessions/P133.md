  not the player array it points to; on N64 that is BSS after D_800DC468); (2) D_800DD5E4 / D_800DD5E8 (s32 elsewhere)
  are compared / stored as their upper halfword (lh / sh), written endian-neutrally as `>> 16` / `<< 16`; (3) with no
  combine flag the asm compares a 64-bit leftover register ((u16) vtx[3].y << 32) with D_800DD5EE, so the combine is
  re-sent unless that y is 0; (4) func_15095380 gets 8 arguments from the asm, its 9th (the texture age) is the caller's

  game-C flag) the plain pointer is used (a wasm pointer has no uncached alias).
- The C uses an if chain, not a switch: the NM ELF's `.nm_rodata` (switch tables) is NOBITS, so whole-function
  harnesses that run build_nm code cannot read jump tables.
- Harness `whole6d40.py`: Ref = nmasm_vis5858 interpreter + mult / mflo / dsll + stubs at the callee addresses;
