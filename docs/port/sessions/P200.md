## 1. Harness gap: DIFFTEST_ARG on float parameters (fixed)
- Finding: `DIFFTEST_ARG N=V` set only the integer slot (a0..a3 / stack). A leading f32 parameter is read from
  f12 / f14, so for `f(f32 x, f32 y, ...)` ARG 0 / 1 changed nothing and every setup ran on random x / y (seen with
  func_15087204: its wall setups never met the wall; dropping `ex = -ex` survived).
- Fix (tools/port/difftest/difftest.py): `_make_inputs` records which slots are FP-register floats (`fslot`);
  ARG on such a slot also sets the f register. `DIFFTEST_ARGF_OLD=1` = old behaviour (forwarded by difftest.sh).
- Selftest: case `cases/func_15087204.c` with the `diagwall` setup: EQUIV as is; `ex = -ex` dropped DIFFER (new),
  EQUIV with DIFFTEST_ARGF_OLD=1 (old miss).
- Past setups: a scan of `docs/port/sessions/p1*` for setups giving ARG 0 / 1 to float-first NM functions found
  only false matches (4-hex file names of other functions: f840 = func_150FF840, 79f0 = func_150F79F0, 32bc /
  1a6c / f490 likewise). Not exhaustive (file names are ambiguous); random trials were never affected.

  since entry (a pass-through a0) is not compared: func_1513472C mutant `handler(0)` stays EQUIV. Checked by the
