## 1. Harness: callee prototypes from the headers the TU includes
- Problem (P232): difftest read callee prototypes from the TU text only (plus two narrow header fallbacks: P93 for
  > 16 arguments, P100 / P134 only when the header gives a non-empty FP-argument set). A callee declared only in a
  header, e.g. `s32 func_150ADA20(void);` in functions.h, had an unknown FP-argument set, so the P214 rule compared
  IDO's scratch f12 left right before `jal func_150ADA20` as an argument: false DIFFER.
- Fix (`tools/port/difftest/difftest.py`, `inc_hdr_text`): when the TU text has no declaration of a callee, the
  headers the TU `#include`s (recursively, `"x.h"` and `<x.h>`, resolved through the TU's directory and the Makefile's
  INCLUDE_CFLAGS dirs) are searched; a declaration found there gives the arity, the float a-register slots and the FP
  argument registers, exactly as a TU declaration would (the candidate is compiled with that prototype). The P93 /
  P100 fallbacks still run after it. `DIFFTEST_INCHDR_OLD=1` = old behaviour, forwarded by `difftest.sh`.
- Selftest: before 95 / 95 (old harness), after **100 / 100**. New cases (case file `cases/func_15109DC8.c` = the
  P232 block without its local `func_150ADA20` / `func_150ADA68` declarations): EQUIV as is; DIFFER with
  INCHDR_OLD=1 (the old false f12 DIFFER); two mutants (life + 1, scale factor) DIFFER. The P134 case
  (func_150F1F80, `cosf` from gu.h) now resolves through the new path, so `HDRSLOT_OLD=1` alone gives EQUIV; that
  case now sets `HDRSLOT_OLD=1 INCHDR_OLD=1` for the old DIFFER, plus a new `HDRSLOT_OLD=1` EQUIV line.

## 2. progress_nm block detection
- Cause: one regex required `#endif` right after the `#pragma GLOBAL_ASM` line. func_150E394C (game_eu_110DB0) keeps
  `extern s32 func_150E394C;` in its `#else` part, so it was counted asm-only. Other layouts missed the same way:
  `#else` with several pragmas (D3880, D2DB0, AC770, 45B90, init_EB00), pragma blocks where the C sits in an
  earlier NM block, `#ifndef NON_MATCHING` blocks (D1760 func_150A48C0 / func_150A5480, 1FB080 func_151D1694).
- Fix (`tools/port/progress_nm.py`, `nm_funcs_scan`): a conditional stack (`#ifdef` / `#ifndef` / `#if
  [!]defined(NON_MATCHING)` / `#elif` / `#else` / `#endif`); every GLOBAL_ASM pragma that the NON_MATCHING build leaves
  out counts as NM (its code is C there: an NM body or a private entry folded into another function's NM C).
  `--old` = the old regex.
