# P328 (port-web, 2026-10-27): cleanup part 1 of 2, the port no longer needs the byte-matching build

User decision: port-web stops depending on the byte-matching decomp build (IDO compiler, splat, asm-processor,
generated asm, GLOBAL_ASM pragmas, NON_MATCHING wrappers, symbol_addrs regeneration). That build is kept on branch
`exact-byte-decomp-wip` (created at port-web 502d9581, pushed). Part 1 (this session) makes the port independent of
it without deleting anything; part 2 deletes the machinery and the docs history.

## 1. What the port took from the matching build (inventory before P328)

Generated by the matching build (gitignored; `make`/splat/verify_all output):

| Input | Read by | What for |
|---|---|---|
| `conker/build/conker.eu.elf` symbol table | port/tools/n64mem.py (via elf32.py), port/tools/icall_gen.py | function starts (relocation classification, functab), C-data object extents (`cobj`), ROM table entry -> name |
| same ELF | port/tools/stubcalls.py, tools/port/arity_scan.py (objdump -d / -t / -s, cache port/build/arity/), port/tools/m2c_sanity.py (that cache) | analysis tools: stub call graph, arity of asm callees, function-pointer tables |
| same ELF (STT_FUNC names / st_size) | tools/port/difftest/difftest.py `addr_names`, `matched_size` | names at an address; reference length of C functions (P243). Silent fallback when the ELF is missing |
| `conker/build/conker.eu.map` | tools/eu_port/rename.py `map_addr` | address of a function to append to symbol_addrs.eu.txt |
| `conker/undefined_syms_auto.txt`, `undefined_funcs_auto.txt` (splat output) + committed `undefined_syms.eu.txt`, `undefined_funcs.eu.txt`, `symbol_addrs.eu.txt` | port/tools/gen_stubs.py `addresses()` (stub kinds, data stub sizes, alias stubs, n64mem labels), port/tools/romabs_check.py (Makefile step + check), difftest.py `symtab` (symaddr, addr2name, knob keys) | "link values": name -> address / absolute number |
| `conker/conker.eu.bin` (splat-extracted ROM image, header+boot+init+inflated game+debugger) | difftest.py `image()` (Unicorn memory: code, rodata, data) and the reference words of C functions | reference machine code and initial memory |
| `conker/conker.eu.yaml` (splat config) | tools/eu_port/datarefs.py `segments()` -> difftest.py `image()`, `vram2rom()` | segment rom/vram/rodata split |
| `conker/asm/nonmatchings/**/*.s` | difftest.py `ref_from_s` (reference code of GLOBAL_ASM functions), tools/eu_port/apply_names.sh (inner-entry glabel check), tools/port/implicit_scan.py (proto_hint column only), tools/eu_port/protocheck.py, tools/port/v0use.py, port/tools/bootpath.py, port/tools/priority.py, many conversion-era tools/eu_port scripts | asm text |
| `conker/Makefile` + IDO (`/opt/ido5.3/cc` in the dev container) | difftest.py `_cc_cmd` (`make -n -B VERSION=eu build/<tu>.o`) and the candidate compile | per-TU IDO flags; the candidate is IDO-compiled MIPS |
| `conker/build_nm/conker.eu.elf` (NM IDO build) + `conker/build/conker.eu.elf` | tools/port/difftest/nmasm_*.py, pi480C.py (whole-function harnesses; not in the selftest) | hand-asm vs NM C comparisons |
| verify_all / NM link / protocheck | tools/eu_port/check.sh --fast/--full, apply_names.sh, rename.py --verify | byte-identical gate |

Not from the matching build (unchanged): the game's code and data are read at run time from the user's ROM
(port/ultra/pc_mem.c; n64mem.py and icall_gen.py read `baserom.eu.z64` at build time for the relocation scan,
memtest expectations and the icall table check). `assets/` (root splat output) and `conker/assets/*.bin` are not used
by the port. The census uses committed headers only (`conker/include`, plus `conker/src/libultra/{os,audio,io}` for
`osint.h`, `piint.h`, `siint.h`... : part 2 must keep those headers or move them). `vbe.py` ROM_ABS / RAM_ALIAS are
literal tables already (romabs_check compares them with the link values).
