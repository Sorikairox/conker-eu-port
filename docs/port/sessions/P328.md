# P328 (port-web, 2026-10-27): cleanup part 1 of 2, the port no longer needs the byte-matching build

User decision: port-web stops depending on the byte-matching decomp build (IDO compiler, splat, asm-processor,
generated asm, GLOBAL_ASM pragmas, NON_MATCHING wrappers, symbol_addrs regeneration). That build is kept on branch
`exact-byte-decomp-wip` (created at port-web 502d9581, pushed). Part 1 (this session) makes the port independent of
it without deleting anything; part 2 deletes the machinery and the docs history.

## 2. The frozen files (`port/symbols/`, the source of truth for names and addresses from now on)
- `symbols.tsv` (16137 rows): every ELF symbol of the last matching build in symbol-table order (tools take the
  FIRST name at an address) + 5 link-file names with no ELF symbol. Columns: name, addr, size, type func/data/none,
  bind, section, segment, link (position in the old linker symbol files = the "link values"; `-` = ELF only).
- `segments.tsv`: rom start/end, vram, rodata split of init/init_data/game/game_data/debugger.
- `ido_cc.tsv`: per game TU (719) the IDO command difftest used to get from `make -n` (difftest still compiles its
  candidate with IDO in the dev container).
- `romimage.py`: the extracted image from the user's ROM at run time (header, boot, init, rzip-inflated game code
  and data, debugger) = splat's conker.eu.bin byte for byte (md5 6d8edea9...). No ROM bytes are committed.
- `symbols.py`: reader (`elf_symbols`, `link_addresses`, `func_sizes`, `segments`, `rows`).
- `freeze_symbols.py`: the one-time generator (`--cc DUMP` for ido_cc.tsv). Not to be re-run after part 2.
Proofs at the split: table == ELF symtab (except the unused section index) and == the 5 linker txt files (same
order); ROM image + table == asm/nonmatchings words for all 1891 GLOBAL_ASM functions (one commented-out pragma,
music_player_apply_volume, had no .s: difftest now gets its ROM bytes instead of an error); inner entry points from
the table == the 65 func_ glabels of the asm scan.
