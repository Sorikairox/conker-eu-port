## 3. difftest: candidate float literals read as 0 (workaround `litsym`)

Hand-repairing P16 DIFFERs showed a recurring false DIFFER: a float literal in the candidate (`-0.3f`, `0.0234f`) is
bit-exact with the rodata word the asm loads, yet the candidate stores 0 in difftest. Replacing the literal by the
rodata symbol (`extern f32 D_X;`) gives EQUIV. Root cause in difftest not investigated (probably how the candidate TU's
literal/`.rodata` relocations are mapped; look at `link_candidate`).

- New `cfix.fix_litsym` (DIFFER fix, first in `DFIXES`): every f32 literal whose bits equal a word the asm loads with
  `lwc1 %lo(D_X)` becomes `D_X`.
- Sweep over the best drafts of all p16 + p17r DIFFERs (`port_work/p17lit/`, script `port_work/p17/run_litsym.py`):
  71 had a matching literal, **19 EQUIV** (18 lint-clean; all inserted). func_150FF854 EQUIV with lint:proto (not inserted).
- Cost: these bodies reference the rodata symbol instead of a readable literal. Once difftest is fixed, the literals can
  go back (value = the ROM word).

## 4. Other tool changes

- `cfix.fix_fptab` (CERR fix, registered): m2c's `*(&D_X + (i * 4))(args)` ("Non-function name referenced in function
  call") becomes `((s32 (*)()) *(s32 *)((u8 *)&D_X + (i * 4)))(args)`. On the 9 such CERRs it makes all compile; none
  EQUIV yet (7 DIFFER: call counts, garbage-register args such as func_151D7814's untouched `a2`).
- `cfix.fix_selfproto` (written, **not registered, untested**): for "redeclaration of FUNC" (the draft's definition vs
  the header's own prototype: `void *` vs `u8 *`, integer widths), re-declares the definition with the prototype's
  types. 33 CERRs in p16 + p17r have this shape. Its test run did not complete in this session (see "Open").
