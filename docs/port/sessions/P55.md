  106146F8: DA380003 105DB9B0   10614700: DE000000 00000000   (x3: three G_MTX + G_DL pairs)

The writer is the C **func_150900F0** (game_BC510.c): it draws `D_800D29A8 = func_1518C900(0xB8)` once per world
piece with a matrix each; func_1518C900 (game_eu_1BA680.c) is an asm stub and returns 0. It is drawn only after the

skips a G_DL to address 0 (counted as bad_addr, logged once: `[gfx] G_DL to address 0 ... skipped`). Not a C bug.
**For the port branch:** convert func_1518C900 (DL / asset 0xB8 getter, 96 calls in 40 s) and its pair func_1518CF74.
