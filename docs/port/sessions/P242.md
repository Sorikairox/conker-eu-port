## 2. Harness finding: aliased callee names hide arguments

func_15031C4C's address 0x15031C4C also carries the absolute symbol `func_1503195C` in the EU ELF. difftest names the
call by the ELF symbol it finds and looks the prototype up under that name, finds none, and then compares only the
argument registers written in the straight line before the jal - so a1 / a2 of func_15031C4C were never compared
(mutants `0x48` -> `0x47`, `0x7A : 0x79` swapped, `0` -> `1` survived in both func_150D3870 and func_150D4ED0).
Workarounds used: func_150D4ED0 with `DIFFTEST_JALARG_WIDE=1` (no false DIFFER there; registry knob); func_150D3870
(WIDE gives false f12 DIFFERs at func_150ADA20) through its test variant `d_3870v.c`, which also declares the alias
`func_1503195C` with the same prototype. Follow-up for the difftest owner: when the call's symbol has no prototype, try
the other symbols at the same address (nm lists both).
