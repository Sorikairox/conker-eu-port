## 1. Harness: longer candidate that jals the next function (coordinator item b, P239 / P241)
- Cause: for a matched-C reference (no .s) the reference was `len(candidate)` ROM words. A longer candidate made the
  reference span the next function, so the reference's `jal func_15030600` target lay inside [vram, end): no stub, and
  the reference ran into the real callee (hang until DIFFTEST_TIMEOUT; the CAND_ALT move never triggered because
  rend == cend).
- Fix (`tools/port/difftest/difftest.py`, `matched_size`): the reference length is the function's own ELF symbol size
  (`build/conker.eu.elf` STT_FUNC st_size; fallback: distance to the next known func symbol). The longer candidate then
  triggers the existing CAND_ALT relocation and the callee is a stub on both sides. `DIFFTEST_REFSZ_OLD=1` = old
  (forwarded by difftest.sh); DIFFTEST_REFLEN still wins. P241's "all trials faulted" did not reproduce with this fix.
- Selftest (case `cases/func_150305E0.c`, the P241 draft): EQUIV as is (was a hang); `1,/0xFF/s/0xFF/0xFE/` DIFFER with
