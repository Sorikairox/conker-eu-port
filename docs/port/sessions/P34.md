## 2. func_150A5858: the level visibility walk + DL filter (game_eu_D2DB0, raw hand asm)

The four GLOBAL_ASM files func_150A5858 / func_150A5BE8 / func_150A5D08 / func_150A5F98 are **one hand-written
routine** (0x150A5858-0x150A606C). The inner glabels (func_150A595C, func_150A5A9C, func_150A5AF0, func_150A5C70,
func_150A5C78, func_150A5C7C) are loop labels; func_150A5D08 (state flush) and func_150A5F98 (box-corner outcode,
args in t0/t1/t2, result in t3) are private subroutines. Nothing else references them. Under NON_MATCHING the C
`func_150A5858` replaces all four (`//DROP` on the other three pragmas).

What it does (`Gfx *func_150A5858(s32 dl, Gfx *gdl, u8 *mtx, s32, s32, s32 mask)`):
1. Clears the per-triangle visibility bytes [*D_800D3668, *D_800D3A8C) (EU 0x800D3A88 / 0x800D3A8C).
2. Walks the node tree D_800DC278 in pre-order. Node: +0 s16 y0 (and hide bits), +2 s16 y1 (and visible bits),
   +4 s16 offset to the node after this subtree (0 = end), +6 u16 half size, +8 s16 x, +0xA s16 z, +0xC s16 first
   child offset (0 = leaf), +0xE leaf triangle list. Every node clears `mask` in +2. Hidden when (+0 & mask) or when
   the 8 corners (x ± half, y0 / y1, z ± half) share an outcode bit; then the whole subtree's +2 bits are cleared.
   Outcode (func_150A5F98) with the view matrix mtx (a2): w = x*m2 + m14 + y*m6 + z*m10: 0x10 when w <= D_800D3A90
   (far), 0x20 when w >= 0 (behind); X / Y (columns 0 / 1): outside when !(w <= |X| * -D_800D3A00[0]) → 8 (X < 0,
   sign bit) or 2; Y: 1 or 4. Visible: +2 |= mask; all corners inside: the subtree is not tested again. Visible leaf:
   vis[i] = 1 for its indices (byte b < 0x80: i = previous + b; else i = (b & 0x7F) << 8 | next byte; the previous
   index lives in $gp across leaves).
3. Copies the level DL to gdl until G_ENDDL (not copied): tri commands (0x05: 1, 0x06: 2, 0x10-0x1F: 4 vis bytes,
   consumed in DL order) are kept when one of their bytes & 1; before a kept tri the deferred state is flushed in
   this order: G_RDPPIPESYNC (when a state bit other than VTX is set), SETOTHERMODE_H (0xEF), G_TEXTURE, SETCOMBINE,
   SETTIMG, per tile 0-7 {SETTILE, SETTILESIZE} (dropped when equal to the tile's current one), LOADBLOCK, the SETTIMG
   seen after a LOADBLOCK, RDPLOADSYNC + LOADTLUT, G_VTX. OTHERMODE / COMBINE / SETTIMG / TEXTURE equal to the last
   emitted one are dropped. Incoming PIPESYNC / LOADSYNC are dropped; other commands are copied.
   SETTILE / SETTILESIZE set the flag word to 0x200 (not |=), as in the asm.
