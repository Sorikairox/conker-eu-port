
The steady state on level 0x21 is the same in node and in Chrome:

```
func_1512C490 call 192 frame 773: mode 00000001 rec 105D46F0 pos 27 1 27 | cam 2A4 27 1 27 at 27 1 27
  eye 332.319 40 -406.221 orbit 18C 0 190 0 194 0 198 0 yaw 2.52768 | obj 106484DC eye 332.319 40 -406.221 at 27 1 27
```

- **Orbit:** |eye - at| horizontally = sqrt(305.3² + 433.2²) = 530. The direction is (sin, cos)(2.52768) =
  (0.576, -0.817). This is P41's formula.
  - On the boot level, the eye first sits at the start table's position (distance 563). On the first update it moves
    to 530.
  - The yaw drifts by about 1e-5 per 4 frames on the boot level, from func_15122EF0's heading correction. On
    level 0x21 it is stable.
  - The orbit only turns when the yaw changes, and nothing changes it without input (§3).
- **obj+0x130..0x150:** dir (0.447, -0.443, 0.777) on the boot level = normalize(at - eye). eye and at are the
  controller's values.
- **Matrices** (`PORT_DLTRACE=400 PORT_MTXDUMP=1`, gfx task 400, level 0x21; gfx tasks run every 4 frames):

  ```
  P load: 1.7113 0 0 0 | 0 2.1445 0 0 | 0 0 -1.0202 -1 | 0 0 -101.0101 0      (fovy ~50, aspect 1.25, near 50, far 5000)
  P mul : -0.8174 -0.0423 0.5745 0 | 0 0.9973 0.0734 0 | -0.5761 0.0600 -0.8152 0 | 37.6237 -1.4755 -525.0085 1
  ```

  The third column is -dir = (0.5745, 0.0734, -0.8152), and |translation.z| = 525, about |eye - at| = 532. The boot
  level's view (task 2) checks the same way: translation (-4934.9, -3592.9, 6645.2) = -R·eye.
- **Level start:** the s16 start (27, 1, 27) and the f32 camera start (175, 40, -183) are plausible for level 0x21:
  its floor vertices are at y = 0, with x / z within a few hundred units. **UNVERIFIED** against an independent decode
  of the start table D_800D212C.
- **Boot level oddity, not chased:** at frame 2, rec+18 y goes from 14 to 1000. The watch first sees it at the
  func_150A067C stub, which is called from the C func_15019F20, while at.y stays 14. It may be a stubbed ground
  query (func_150ACEA0 is also called by game_eu_1365E0, game_eu_17D3C0 and game_eu_1D5710). It does not matter on
  level 0x21.
