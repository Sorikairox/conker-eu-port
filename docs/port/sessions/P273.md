# P273 (port-web-b, 2026-10-25): Berri's see-through hand = renderer ALPHA_CVG_SEL cut-out

Worktree `~/conker-wt/web2`, branch `port-web-b` (from port-web 23d95021, merged port-web 4d69d9f1 = P272 glass fix).
Repro: `docs/port/sessions/p273/run.sh DIR SECS [EXTRA_QUERY]` (det=2, muted, waits for other headless Chrome).

## Cause
p158f dump at frame 12780 (~255 s, Berri dancing): her hands are draws with oth 192C3F/04D12078, cc 26A080/151492FF,
an **I8** 32x32 mip chain (alpha = intensity, texel (0,0) = 0). othermode L 0x2078 = RM_AA_ZB_OPA_SURF: ALPHA_CVG_SEL
without CVG_X_ALPHA. On the RDP that only routes coverage into the blender alpha; the combiner alpha never changes
coverage. The renderer discarded alpha < 0.5 for every ALPHA_CVG_SEL draw, so the dark texels of the I8 hand vanished.

## Fix (port/gfx/gfx_f3dex2.c apply_state)
Cut-out (uCvg) only when ALPHA_CVG_SEL **and** CVG_X_ALPHA are set (TEX_EDGE; leaves 0x3238 keep their cut-out).
`?p273oldcvg=1` = old behaviour. Also: p158 dumps now keep up to 600 textures (seen table 1024).

## Milk glass (coordinator lead)

RM XLU 0x49D8 + fog cycle), blended translucently over it (faint thumb visible through). Looks consistent with RDP rules.
