## 1. D_80084550

`port/tools/n64mem.py` classifies a .data word that sits exactly on a function start as `F`. It is relocated at load
to a wasm table slot through `n64mem_tab.c`, which declares each target as `int f(int, int)` (the call-site
signature). ROM (game_data, inflated) 0x80084550: [0] = 0, then [1..24] = 150D87CC 1503211C 1503216C 150F5C30
150322B8 1503356C 15033618 150C78E0 150334A8 150C8C30 15033730 150E0350 150337A8 15033A7C 15033AD4 15033B28 15033CB8
15033DC8 150D88E8 150340F0 150F5FD4 15033698 150341FC 15034260; then 0 and data pointers (another table).

- Asm stubs among them: [3] func_1503216C, [5] func_150322B8, [19] func_150D88E8, [21] func_150F5FD4. The others

  the list. After B: `rec model 1 joint 9 callback 5 sub 0 timer 65535 mtx 0 target 0`, then a second one with
