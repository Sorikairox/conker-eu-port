## Tool changes

- `DIFFTEST_POKE="ADDR=VAL[*N],..."` (hex; forwarded by difftest.sh): fixes lazily created memory words for both runs. It
  narrows the inputs only. Use it for sentinels that random words never produce (-1 empty slots, etc.).
- protocheck: skips function-like macros (`#define NAME(` in any header/source), text inside comments, calls through
  `->`/`.` members and local function pointers, and treats `extern` header prototypes that SIG cannot parse
  (function-pointer parameters, e.g. `osCreateThread`) as known.
- Not done (denied by the auto-mode classifier): an opt-in to trust explicit `(void)` prototypes in difftest's arity check.
  The first `func_1501878C` draft hit that false DIFFER: the ref loads a0 for a DL store right before `jal func_10004674`.
  Writing the DL commands with the GBI macros changed the candidate's registers and avoided it.
