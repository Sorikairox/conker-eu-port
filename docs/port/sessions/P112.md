## Harness: indirect-call arity (P106 open question) - fixed

Cause: for a call of an unknown function (no prototype; every table handler reached through `jalr`) difftest counted
only the argument registers written in the straight-line run before the call. Natives 5 / 6 load a1 (`lw a1, 4(a0)`)
before branching to the shared jalr tail, so a1 never counted and an `args[1]` -> `args[0]` mutant survived.
Fix (`difftest.py`): every run records the argument registers its own blocks wrote since the previous call (path
sensitive, per executed block); for a `jalr` call of an unknown function the reference's set widens the compared count.
`DIFFTEST_JALR_DYN=0` turns it off (forwarded by difftest.sh). Selftest case `func_150AE60C` (cases/, ROM data, REFLEN
104 bytes): as is EQUIV, the args[1] -> args[0] mutant DIFFER (before the fix: EQUIV). Selftest 51 ok / 0 failed.
Note: DIFFTEST_REFLEN is in **bytes** (P106 notes did not say).
