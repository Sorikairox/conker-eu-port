## 1. Harness: arguments at direct calls (jal)

### What really hid port-b's func_150768DC x-swap
func_1505A630 HAS a prototype (`u16 func_1505A630(f32, f32, s32)`, functions.h), so the FPR compare used the
known-prototype path. But game_A28B0 contains `    return func_1505A630(temp_v0[0] - ..., ...);` and difftest's
declaration test (`_DECL_PRE`) took `return` for a type: that call statement was read as func_1505A630's prototype,
its `[` made the FP-argument set empty, so **f12 / f14 were never compared at any func_1505A630 call in that TU**.
- Fix: `_DECL_PRE` no longer accepts `return` / `else` / `case` / `goto` / `do` / `sizeof` as a type
  (`DIFFTEST_DECLKW_OLD=1` = old). Also `proto_fregs`: a K&R declaration `T f();` is now "unknown" (look further /
  headers), not "no FP arguments" (same knob).
- port-b's draft + the x-swap mutant with its P210 setup `one`: DIFFER now (f12 ref=0x42480000 cand=0xC2480000),
  EQUIV with DECLKW_OLD=1. Any function whose TU has a `return func_X(...)` line before func_X's other uses had
  func_X's FP args (and possibly its arity / float slots) wrong before P214; port-b should re-run its A28B0 mutants
  (func_150768DC, and others calling func_1505A630 / any float-arg callee returned directly).

### Unknown-prototype jal stubs
- Default change: FPRs compared = the ones EITHER side set in the straight-line run right before the jal (before:
  only those BOTH sides set there). `DIFFTEST_JALARG_OLD=1` = old.
- The brief's wider rule ("every f12-f15 / a0-a3 either side wrote since the previous call") is implemented but
  **opt-in** (`DIFFTEST_JALARG_WIDE=1`): as default it gave false DIFFERs, because IDO keeps locals / temporaries in
  arg registers between calls: func_151DE100 (selftest, 4 cases failed) keeps a byte local in a0 across its call
  of the no-argument func_1517F54C; func_1508A63C has the race mode in a3 and dz in f12 at its func_150859AC call.
  A "both sides wrote it" variant for GPRs also gave a false DIFFER (func_1508A63C a3: 0xB7 vs 0x7D0).
- Selftest hook `DIFFTEST_NOPROTO=NAME,...` treats those callees as having no prototype.
- Forwarded by difftest.sh: DIFFTEST_JALARG_OLD, DIFFTEST_JALARG_WIDE, DIFFTEST_DECLKW_OLD, DIFFTEST_NOPROTO.
