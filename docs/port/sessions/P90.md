- 0x11 with b5 < 0: the N64 indexes the stack copy of D_800844D8 with a negative index (bytes below the copy); C reads

- 0x34 with b5 < 0: N64 uses an uninitialised stack byte as the index; C uses 0.
- 0x5F/10 with b5 not 0..2: N64 passes an uninitialised pointer; C passes the first table entry.
