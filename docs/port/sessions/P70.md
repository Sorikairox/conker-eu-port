## Notes / gotchas

- **Data addresses in knob setups must be EU**: the D_ names are US-style; the EU address is in
  `conker/undefined_syms_auto.txt` (D_800CC2D0 = 0x800CC6F0, D_800C4000 = 0x800C4420, D_800BE9E4 = 0x800BEE04,
  D_800BEAC0 = 0x800BEEE0, D_800DBFF4 = 0x800DC424, D_800C35EA = 0x800C3A0A, D_800BE9B4 = 0x800BEDD4,
  D_800C3E78 = 0x800C4298, D_800D1588 = 0x800D19A8, D_800C5A90 = 0x800C5EB0). The 0x80098xxx rodata tables keep
  their names. With the US object address the first BCAC runs returned before any call (looked EQUIV).
- difftest compares stray a1 / a2 of float or 2-arg callees unless their prototype is in the **candidate text**
  (sinf, cosf, func_15048A70, func_150484A0, func_15048360 are declared at the top of the BCAC block for that).
- **func_15030448** (attachment free) is written (`docs/port/sessions/p70/draft_0448.c`) but not inserted: difftest keeps
  comparing a2 of func_100043B4 (2 args) although the candidate declares it; to look at next session.
- func_1503BCAC: the 5th offset vector (tip) is computed but never read by the chain loop (kept, as in the asm).
  In modes 0 / 1 the asm passes an unset stack word as func_1503CE88's fade; func_1503CE88 reads it only in mode 2,
  the C passes 0.0f.
- func_1503CE88 / func_1503A968 matrix callees are stubs in difftest (memory effects not compared; their args are).
