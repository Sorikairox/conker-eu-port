## 1. func_151F94E0 mp3_imdct36_hybrid (game_eu_226870, 958 words)

Long-block 36-point IMDCT of one subband + windowing + overlap-add, the maplay / JLayer `inv_mdct` scheme (prefix sums,
two 9-point DCTs, 9 butterflies, frequency inversion of odd samples in odd subbands). The asm is register-scheduled
straight-line code (no calls); the C keeps the asm's evaluation order and its signed constants (read from the ELF at
0x800B1060..0x800B1168, written as 9-digit literals that round-trip bit-exactly), so results are bit-identical.
Signature `void (f32 *in, s32 sb, f32 *out, f32 *prev, f32 *win)`; game_221290 declares it with
`struct asistream_4f64 *` (same ABI, 5 args, matches its 2 call sites).
- random 16 / 16 EQUIV; 32 setups EQUIV (`s94e0.txt`: realistic spectra (gaussian, decaying with frequency), the three
  long-block windows (sine_block is BSS: computed like func_151F3DE0), sb 0 / 1 / 2 / 7 / 30 / 31 / -1 / 0x101, zero,
  -0.0, impulses, 1e7, 1e-30, random magnitudes; out buffer prefilled). ARGMEM n/a (no calls; the memory compare
  covers in / out / prev).
- mutants 65 / 65 (`m94e0.txt`) + 16 / 16 (`m94e0b.txt`). The first run had 16 "survivors": last-digit literal
  changes that round to the same float (no-op mutants, removed); `m94e0b` changes each of those constants by 1 ulp
  (all killed).
