## 1. func_150A86B0 (D5E90_anim.c)

Arguments (P48 §2): `(&D_800C42A8, m, anim = obj+0x2D0, skel = D_800C5000[id], n, buf, remap, height)`.
- anim == NULL: copy m into one matrix (func_150A8680).
- Work tables: three tables of 12 * count bytes (count = header byte 1 = joints + 1) that the asm keeps *below* its
  stack pointer; in C a stack array sized for count <= 72, in the same order (D_80088918 = D_80088908 translation
  offsets, D_80088914 scales, D_80088910 Euler angles; animation 2 continues after animation 1 in each).
- Decoder (func_150A8EF8): frame fraction w = round((time within the key group) * 1024) (cvt.w.s, RNE), key frames
  data and data + next; header byte 7: 0x10 = no interpolation (fraction to D_80088920), 0x20 / 0x40 skip a
  halfword, 0x80 = translation offsets (64-bit mask, 3 x s16 per set bit), low nibble = root z width, 0x40 = root z
  is root motion (D_800888F4 / F8 / 900); byte 6 nibbles = root x / y widths; then per channel a u16 descriptor
  (base & 0xFFF0, width, 0x10: a scale value follows). The 64-bit ldl/ldr window is a plain MSB-first bit reader.
  Then the per-object adjustments buf ({u16 offset, s16 value} up to 0x1000; < 0x800 adds to an angle, else scales).
- One animation: full-turn sin/cos (11-bit table D_150AA11C) per axis, rows scaled by the scales / 0x4000.
- Two (animation 2 with weight +0x3C, or the next key pair with D_80088904): half-angle quaternions, sign-aligned,
  `qa * (1 - w) + qb * w`, normalised through 2 / |q|^2 into the rotation; scales and translation offsets blended.
- Composition: first joint's parent = m moved by the root position / 1024, the others' = parent slot's matrix;
  column 3 is never written. remap[slot] != 0 calls `jtbl_8008891C_game[k] = {fn, flag}` (ROM: 5 entries,
  func_15036FD8, 15037224, 1503A8FC, 1503A968, 1503AAE0, all flag 1; the asm's flag-0 tail jump is not modelled).
- Float operations are in the asm's exact order (`0.0f - x`, not `-x`); the harness byte-compares the matrices.
Harness: VR4300 interpreter (nmasm_vis5858's, extended with mult/mflo, sra, sub, 64-bit shifts, ldl/ldr/sdl/sdr,
div.s, floor.w.s, .game data reads) for the asm, Unicorn for the IDO C; RDRAM compared except the stack pages and the
5 work-table pointers (D_800888EC compared as NULL / not NULL); callbacks are stubs that log (index, arena bytes).
Mutants (`port_work/p51/mutants.py`, log `mutants.log`): rounding, 11-bit sign extension, quaternion sign, matrix
op order, adjustment shift, offset scale, scale-blend default, callback index, root motion: DIFFER. EQUIV: `time <=
base` (equivalent: both give fraction 0) and the mask limit 64 -> 32 (Conker has 28 channel joints; models with
more than 32 are UNVERIFIED for bits 32..63).
