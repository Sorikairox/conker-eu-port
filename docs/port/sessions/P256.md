## 3. Harness: DIFFTEST_ARGMEM dereference `N*OFF:LEN`

  Needed for func_15104A80's key {count, part list pointer, owner}: the list is a stack copy, so its address differs
  between the builds and only the dereferenced bytes can be compared. Old forms unchanged (`N:LEN`, `N+OFF:LEN`).

  D_800A275C -> D_800A2768 swap. Selftest result: 125 ok, 0 failed.
- Lesson: my first func_15104A80 run keyed ARGMEM on 151494E0 (the US name's address); the EU jal target is
  15149A50, so the compare silently did nothing and 12 / 16 mutants "survived". The `[knob callee never called]`
  flag was on the random line but random trials never reach the call; read the setup / mutant counts too.
