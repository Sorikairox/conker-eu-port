  under aliasing).

stack: frame-layout artifact, inconclusive). `p53/eed0knobs.sh` setups a-j (area 0 only, mixed floors / ceilings,
all areas, argF no-fallback, y above / below the previous y, area 3 skip flag, nothing a floor, area 3 only,

## 2. func_150A44A4 (floor height of a triangle)

Hand asm ("Handwritten function"): m2c gives no draft. The C (game_eu_D1760.c) sorts the vertices by z, takes x / y
on the edge A-C and on A-B or B-C at z = pz (24.8 fixed point, wrapping `mult` products), checks pz's x between
them, interpolates y and clamps it to the triangle's y range; `*out = v / 256`. Inputs: 3 vertex pointers (a2) or
9 inline s16 (a3; all-zero first or second 8 bytes = none). Notes:
- the asm keeps s5-s7 / fp in f1-f4; cvt.w.s rounds to nearest (macro `A44A4_RINT`);
- a zero x span divides by zero on the VR4300 (no effect on the result: x - x2 = 0): `a44a4_div` returns the
  VR4300 quotient and avoids the IDO `break`;
- func_150A48C0 branches to the last `jr ra` of func_150A44A4.s: kept as `src_eu/nm_asm/func_150A44A4_tail.s`.
Test: `nmasm_floor.py` (VR4300 interpreter vs Unicorn, random triangles incl. vertical edges, points on vertices /
edges, .5 ties, packed unaligned input, zero halves): 1500 x seed 1 and 600 x seed 2, 0 diffs (75% hits).
Mutants (`p53/mutant.sh`): no y clamp, cvt.w.s -> trunc, no second zero check: DIFFER; `d2 < d1` -> `<=` is an
equivalent mutant (only d1 == d2 == 0 hits either way).

## 5. Wall engine map (func_150AB6D0 / func_150AC8C4 -> func_150AB708), for the next session

Not converted. What it is: a sliding cylinder-vs-triangle resolver. Frame 0x268 shared by both entries.
- Entry stubs store 4 continuation pointers at sp+0x1D0..0x1DC (jumped to with `jr`): AB6D0 = D_150AB988 (box from
  the move), func_150ABB24 (tree walk), D_150ABE68 (per-triangle test), D_150AC78C (write the position back);
  AC8C4 = D_150AB8EC, D_150ABAEC (sin/cos of +0x40 heading), D_150AC960, func_150ACE90. sp+0x28 = required
  triangle flag mask (0 for AB6D0, 0x0E000000 for AC8C4); AC8C4 returns at once if rec+0x20 > 0 and clears
  D_800CC1C0[rec index].
- Args: f12 / f14 / a2 (float bits) = target x / y / z, a3 = record, stack 0x10 (sp+0x278) = "mark touched objects".
  Returns sp+0x164 (1 = moved by a wall).
- D_800DC280 (area kind) 2 = world objects (func_150A69A8 + func_150A49D0 on D_800D3C00, tables D_800DC328 /
  D_800DBEF4), 3 = the 25 records (D_800CC2D0 .. +0x4F4C, +0xF8 & 0x4000, +0x264 / +0x268 / +0x26C tables).
- Private registers: s0 = BSP node (D_800DC278: +4 next, +6 radius, +8/+0xA centre x/z, +0xC first child,
  leaves at +0xE: byte lists of triangle indices, 0x80 = 2-byte index), s2..s5 = integer x/z box (func_150AC6A4),
  fp = integer y, s6 = triangle index, s7 = leaf cursor, gp = count of the visited list at sp+0x6C (100 u16),
  f29-f31 = start point, f23-f28 = triangle vertices (func_150AC824 rotates them into the heading frame with
  sin/cos at sp+0x30 / 0x2C), f19-f22 = plane from func_150AAF00 (the box test; P22's func_150AB278 is its
  sibling entry). Triangle bounds D_800DC270 (x/z, 8 bytes) and D_800DC274 (y, 4 bytes), vertex offsets
  D_800DC26C (12 bytes), flags D_800DBE5C.
- Per hit (func_150ABF88): plane normal length, the 0x3F000000 slope test unless flag 0x1000000 / D_800CC1F2,
  push-out along the plane (func_150AC200 projects onto the triangle, three edge cross products, func_150AC3CC
  nearest point on the edges), new position at sp+0x34..0x3C, box recomputed, walk restarts (func_150AC694 sets
  the result 1 and jumps back through func_150AC6A4 with t0 = return label).
Plan stays as P50 §3: one C function with the continuations as a `mode` switch, static helpers for func_150AAF00 /
func_150AC824 / func_150AC200 / func_150AC3CC, `nmasm_vr.py` as the reference on a level built by
`nmasm_level.py`'s pipeline (D_800DC26C..78 / D_800DBE5C come from the level load).
