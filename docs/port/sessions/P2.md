- Each DIFFER fix is tried at most once per draft; 7 rounds per draft.
- An EQUIV with a lint flag no longer ends the search: the lint fix is tried, then the other drafts, and a
  lint-clean EQUIV wins. `--insert` inserts lint-clean EQUIVs only.
- `port_work/<tag>/best/<f>.c`: the best draft of every function (with its fixes), for nmrepair.
- `CONVERT_P1=1` restores the P1 fix set (for measurements). `CONVERT_BUDGET`, `DIFFTEST_BUDGET`,
  `DIFFTEST_NOLEARN` are passed into the container.

### difftest

- **Automatic input templates (pointer learning).** When the reference faults (an input the original
  cannot handle), the trial is re-run with a load trace: the base register of the faulting load/store is
  traced back to the memory word, argument or stack arg it came from, which is then forced to a valid
  heap pointer. Up to 8 rounds per trial (`DIFFTEST_LEARN`), applied identically to the candidate.
  EQUIV lines report `N trials via learned pointer inputs`. Effect: many formerly inconclusive trials now
  run (`func_151BCD44` 33 → 64 ok, `func_15060BE0` 44 → 64). The 4 pilot UNSURE functions are not
  fixed by it: `func_150A7D00` uses `sd` (MIPS III, Unicorn MIPS32 raises an exception), and
  `func_150B0574` / `func_151DAE28` hit a Unicorn `UC_ERR_EXCEPTION` on a branch right after a stubbed
  call (not understood; the fault PC is reported as 0, so learning now tracks the last PC with a code hook).
  A per-function template file was not needed for the faults seen; the learned one is automatic.
- The reference keeps the delay slot `nop` of the final `jr ra` (it was stripped with the padding).
- `-v` on a DIFFER prints the diverging trial: inputs, learned pointers, both call traces (a0–a3,
  `*` marks the first different call), the final memory bytes that differ and the return values.
- selftest: 13/13 still pass.

### New tools

- `tools/port/nmrepair.sh FUNC [draft.c] [--trials N] [--wide W]`: the best draft (newest
  `port_work/*/best/FUNC.c` and its results row), the difftest verdict with the divergence detail, and
  the draft and the asm side by side. Example: `func_1503DF2C` was repaired in one edit from this view
  (m2c stored the call result through a `u8` deref: `*(s32 *)(*temp_s2 + var_s1) = ...`).
- `tools/port/progress_nm.py [--list]`: matched / NON_MATCHING / asm-only per segment (from
  `conker/progress.csv` plus the NON_MATCHING blocks in src_eu).
- `tools/port/protocheck.py [FUNC...]`: prototype consistency of the NON_MATCHING bodies (definition vs
  other prototypes, the callee prototypes a body declares vs the callee's definition, implicit calls).
  0 problems on the inserted bodies.
