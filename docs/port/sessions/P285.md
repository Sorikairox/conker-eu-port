## Task 2: D5E90 wall helpers

### nmasm_walls.py `--unit` mode (new)
`python3 ../tools/port/difftest/nmasm_walls.py N SEED --unit all|aa950,aa9b0,...` calls one private helper:
reference = the asm entry on the VR4300 interpreter with the FPRs / GPRs set; candidate = new NM-only
`s32 nmw_unit(u32 entry, u32 *io)` in D5E90.c (io = f0..f31, 26 GPRs, the 0x268-byte engine frame; nmw_walls
got an `io` argument, a switch jumps to the helper's label, `done:` writes the registers back). Compared: memory and
each helper's outputs (v0 / f23-f31 / f19-f22). Inputs: half from an exact pool (0, -0, halves, small ints) with
points put exactly on a face / edge / corner plane, half random; crossing segments with diff = the end points'
outcodes (as the caller); small triangles for point-in-triangle; no NaN / inf.
Helpers: aa950 aa9b0 aaa88 aab58 aacf4 aae80 aaf00 ac824. Baseline (asm2c code) 450 trials EQUIV.

the exact-plane inputs; segment / point / plane 18/25, then 2 of 4 re-run survivors killed with the new inputs.
Justified survivors:
- `!(z <= hz)` for `z > hz` (box outcode): differs only for NaN.
- `c2 <= lo` (point in triangle bounds): when c2 == lo the assignment is a no-op.
- `cx <= 0` (sign3): cx == 0 also gives |cx| < 1, which masks that bit out.
- `mask 0x37 -> 0x3B` (-y face lerp): bit 4 cannot be set on the -y face; bit 8 only when the lerped y rounds below
  -hy while all other faces pass (rounding-only; the +x analogue was killed that way).
- `|cy| <= 1` (sign3): needs an edge cross product of exactly 1 that changes the result: not hit.
AAC58 / AAB24 labels and their dead return addresses were removed (only called from the rewritten helpers).
The AACF4 asm compares with f18; its only caller func_150AAF00 sets f18 = 0, so the C uses 0.0f.
Note: nmasm_walls.py was edited while mutants 24-25 of hmut_b ran (rule slip; both killed, unmutated re-check EQUIV).
