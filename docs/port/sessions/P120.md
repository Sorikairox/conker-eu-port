## Harness lessons

- Stub out-param writes (OUTW) to a page nothing touched before fault (`UC_ERR_WRITE_UNMAPPED` at the stub): put
  the out-param target in a page the function already read (P120 put the camera in the record's page).
- DIFFTEST_ROMDATA=1 drops pokes into .data (the record pointer): poke the tables with their ROM values instead.
- ARGMEM on a partly written stack array compares garbage: the reference's array can overlap a live local
  (func_151E3AE4's x[15] = the alpha local). Use a length that is fully written for the setup's count.
- Layout mutants only die with ARGMEM (stubs ignore the array contents); run them with ARGMEM setups.
