## Lessons
- Run a variant **grid** (operand orders x named/plain/pointer key x default-arm form) through one `tryall`, then hand the best-register variant to the permuter; the permuter finished the DIFF1 that s71's permuter run (from a different start) could not.
- A grid built for one function transfers to siblings in the same file: the 0x2D bodies of 15135480 matched 151347CC in one call.
- `b L` to the next instruction in both arms of an inner if/else = the outer `if` has an `else` arm that IDO merged into the compare block.
- Per-arm address re-materialisation (`addiu v1,s0,K` in each arm's delay slot) = function-level pointer + a declaration at the top of the arm; arm-local pointer locals fold into offsets instead.
- Arm-local declarations also change instruction scheduling of the arm (15156598), not only delay slots.
- `func_151A6520`: a second remote permuter run (900 s, from `wim`) went 263 -> 250, still DIFF30.
