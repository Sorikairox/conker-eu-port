## Tools (all in `tools/eu_port/`)
- `linejoin.py draft.c outdir [max=128] [func]`: same-line variants (all runs joined, each run, every triple, every pair, tilings, pairs of joins; split variants for already-joined lines), `index.txt`.
- `ljcollect.py out_list [max_off] [min_off]`: near-miss drafts of a slice ("func path" lines; all draft sources per function).
- `ljsweep.py list name [par]`: screens any number of drafts of many functions in one container run (dir `conker/build/lj_<name>/<k>/`, does not touch `build/ta`); ~10 drafts/s with par 8.
- `ljpipe.py base.res outdir [maxdiff] [ljcap]`: best draft per function -> baseline + linejoin + blkvar list. `ljbest.py sweep.res sel.txt`: improvements + changed/improved/OK counts per variant kind.
Whole sweep for a slice: `ljcollect.py l.txt` -> `ljsweep.py l.txt base > base.res` -> `ljpipe.py base.res w > w.txt` -> `ljsweep.py w.txt w > w.res` -> `ljbest.py w.res w/sel.txt` (about 10 min for 3,000 variants).
