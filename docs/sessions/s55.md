## New tools

- `vecfix.py <in> <out> [funcs]`: rewrites runs of m2c scalars `spXX` (same type, 4 apart, lowest one's address taken) as one array.
- `spinline.py <in> <out> [funcs]`: inlines `spXX = <call>;` into its single later use at the same indent.
- `opshift.py <func.diff>`: opcode-level difflib alignment of the `repair_try` diff: shows only real insert/delete/replace spots, which separates
  "register renaming" (no shifts) from "different instruction count" at a glance. `rt.sh <func> <draft.c> [n] [m]` = `repair_try` + `opshift`.
- Pipeline used: `gensome.sh pool` -> `ARGFIX=1 m2cfix.py list dir` -> `vecfix.py` -> `spinline.py` -> container `screen.py` (script in
  `conker/build_port/pipe.sh`, untracked; 4 commands). Pool list in `conker/build_port/pool.txt` (untracked).
