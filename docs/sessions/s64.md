## Lessons
- Read what the reference *does* before touching declarations: two of the "register" near misses were semantic (struct copy, pointer stride).
- Slot puzzles in this family came from m2c/permuter named temps; deleting names (inlining single-use values, letting IDO CSE repeated loads) fixed three of them.
- `tryall` with 8-24 generated variants per hypothesis (python template) was the efficient loop: one tool call per hypothesis.
