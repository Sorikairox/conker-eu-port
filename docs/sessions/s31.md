### Tool: `tools/eu_port/gfxfind.py [--list] [--untried] [--hints F...]`
Finds live GLOBAL_ASM functions (a `.s` stays on disk after a match, so it checks for a remaining `#pragma GLOBAL_ASM`) that store `lui` constants whose top byte is a GBI opcode
(`sw r,0(base)` + `sw x,4(base)`, or an opcode `lui` or'ed with a variable) and advance a pointer by 8. Default = counts, size buckets and per-command tags;
`--list` = one line per function (size, logged/new, tags); `--untried` hides logged ones; `--hints F...` prints draft macro lines (gSPMatrix flags, gSPSegment index, gDPSetPrimColor/EnvColor
r,g,b,a, gDPSetCombine, gSPSetOtherMode sft/len, gSPVertex n/v0, gSP1Triangle, gSPTexture ...) decoded from the constant words; word 1 shows as `0`, a const, `&sym` or `w1?`.

### Gfx macro recipes (new this session)
- Argument order of the packed macros follows the *word*: `0xFA00F200` = `gDPSetPrimColor(gdl++, 0xF2, 0, r, g, b, a)` (m = 0xF2, l = 0), not `(0, 0xF2, ...)`. RGB from a byte table: repeat `arg3 * 3` in every
  index expression, do not hoist an `off` local (it changes the register allocation: DIFF7 vs OK).
- `0xEF302C0F`+`4` = `gDPSetOtherMode(gdl++, 0x302C0F, 4)`; fill colour `(GPACK_RGBA5551(r,g,b,1) << 16) | GPACK_RGBA5551(r,g,b,1)` with `u8 r,g,b` stack params; a callee that takes and returns the
  `Gfx *` in the middle: `gdl = f(gdl); ... return g(gdl, ...)`.
- `0xE4/0xE1/0xF1` = `gSPTextureRectangle(gdl++, x << 2, y << 2, (x + 8) << 2, (y + 12) << 2, 0, s, t, 0x400, 0x400)`. Write the shifts as `<<`: `(x + 8) * 4` is folded to `x * 4 + 32` by IDO and the ref
  does `addiu; sll`. Keep `col = idx % 8; ... (idx - col) / 8` as locals (reused remainder; `idx / 8` alone gives different code).
- `0xDC080008` (+ pointer) = `gSPViewport(gdl++, D_800BE628 + arg1 * 0x180 + D_800BE9C0 * 0x10 + 0x40)`. A `(s16)arg1` argument must be inline (a named `s16` local grows the frame by 8). Residue DIFF5: order of
  the two global loads; permuter 100 s did not solve it (`func_15019BB8`, `func_15019464`).
- `0xDB06xxxx` = `gSPSegment(gdl++, seg, value)` (segment = offset/4); `0xDE000000` = `gSPDisplayList`.
- Gfx functions that return the pointer are `Gfx *f(Gfx *gdl, ...)`; extra non-pointer params are `s32` unless the ref `andi`s them.

### Other recipes (new)
- **Switch with a `return` default and common `return 1`** (`func_1514F6A0`): `switch (a1) { case 0xD: ...; break; case 0xE: ...; break; default: return f(a0, a1, a2); } return 1;` The if-chain gave SIZE-1/-2;
  the ref sets `v0 = 1` in the delay slot of the first `beq`. A callee wrapper passes `arg0, arg1, arg2` through (3 params even when the wrapper uses two).
- **Case order in the source = body layout**, not compare order (`func_1509F764`: compare chain 0,1,2 but the bodies are laid out 1,0,2, so write `case 1:` before `case 0:`).
- **Explicit else beats ternary / default+if** for a `0xFF` default (`func_1503DD2C`: `if (r != NULL) v = r[i]; else v = 0xFF; return v;`); computing `q = p - 0x38` *before* the NULL test makes IDO keep an explicit
  `addiu v1,v0,-0x38` instead of folding the offset into the loads.
- **List search with a flag**: `next = n->unk14` loaded before the compare, `while (n && !found) { next = ..; if (k == ..) found = 1; else n = next; }`, then `if (out) *out = n;` (`func_1514F250`).
- **Prototype first**: a callee declared in another file only (`s32 func_151149AC(u8)`) must get a forward prototype in the draft, otherwise the `andi a0,a2,0xFF` is missing; a `static`-like callee defined later
  in the same file (`func_1509FB40`, `func_151E5D28`) needs a forward prototype too. A name used as a *variable* in the file (`extern s32 func_151E5564;`) must be changed to a function prototype before the C body.
- A callee file declaring `s32 f(u8 *)` with a definition that falls off the end (no `return`): write no `return` (a `return 0;` adds `move v0,zero`) (`func_15179314`).
- Declaration order moves a lone spill slot: `u8 *next;` before `u8 *p = ...` gave slot 0x20 (`func_15179314`, `// fakematch`).
- Small tables: `s16 *p` writes with `return arg0 + 4` (`func_150BE938`); struct127 stride 0x32C via `(u8 *)&D_800CC2D0[arg1]`.
