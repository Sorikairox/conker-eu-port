## Tools
- `tools/eu_port/mydis.sh <func>`: disassembles column 2 ("mine") of `repair/<func>.diff` (the `**` rows have the ref in col 2 in the diff itself, hence the sed). Much faster than reading hex columns.
- Screening drafts with a callee already used implicitly in the same file: first line `//HOIST <prototype>;` in the draft.

## Pitfalls
- `mv conker/build/hand/func_*.c conker/build/hand_done/` with one file and no existing directory renames the file to `hand_done` (mkdir first); `sed -i '' '/a\|b/d'` does not do alternation on BSD sed (use `perl -ni -e 'print unless /a|b/'`).
- `rodata_split.py --own X --resplit` after reverting the yaml: `git checkout` the .c file and edit the yaml back by hand, then re-split (about 3 min each).
- Remote permuter jobs queue behind the other agent's (Mac mini load average ~40): a 900 s job takes 15 min wall; a permuter `Killed` message at the end is the `timeout -k` and harmless.
