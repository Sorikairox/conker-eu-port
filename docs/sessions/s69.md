## Key finding: shape D = a declaration in the arm
Shape D (`store; jr ra; nop`, ~170 functions tagged by `shapes.py --list D`, open since session 7) is the s66 basic-block boundary. The block that ends with the store **declares a local**; IDO starts a new basic block at the declaration, the jump after the store sits in a block of its own and the delay-slot filler has nothing to move.
- `func_151AEBF0` (the s23 representative, "only the slot differs"): 7 of 8 boundary variants OK at once; `{ }` without a declaration, `;`, and wrapping the whole arm (DIFF5) do not work.
- Natural forms: a used local in the arm (`s32 *p = (s32 *)(arg0 + 0x44); *p = 0;`), per-arm pointer locals (`u8 *p = arg0 + 0x28;` in each `if (arg2 == K)` arm, `func_151A98CC`). Otherwise an unused `s32 t;` (labelled fakematch).
- The s51 label fakematches (`func_15193850`, `func_150FE08C`) are the same thing.
- `store; b L; lw ra` with the store outside the slot (`func_151D51E8`, `func_1519ED88`): same fix.

## Tools
- `tools/eu_port/blkvar.py draft.c outprefix`: one variant per if/else/loop body with `s32 blk_t;` at its top, plus `_ball`; prints the file names for `m2c/tryall`.
- `tools/eu_port/putc.py func draft.c [--dry]`: replaces the function's `#pragma GLOBAL_ASM` in `conker/src_eu` with the draft (honours `CONKER_ROOT`).
- Note: `m2c/tryall` / `screen.py` only screen functions that are still `GLOBAL_ASM`; to re-test a matched function's variants, revert it first.

## Lessons
- An unexplained unfilled slot after a store, a jal or a branch: try a declaration in the block that ends there before anything else (`blkvar.py` + `tryall`, one call).
- Where the ref keeps two registers for one value (`or a3,v1`), the source re-reads the memory (`*p`) in the other arm instead of using the named copy.
