# Session 62 (main, game < 0x130000): fixchain over the s57 large-function pool

New tool `tools/eu_port/fixchain.sh <list> <outdir>` (outdir under `conker/`): per draft in `repair/fresh/` it builds variants
v0 = `m2cfix.py` (declfix + `ARGFIX=1`), v1 = v0 + `spdecl.py` + `fnptrfix.py`, v2 = v1 + `vecfix.py` + `spinline.py`, v3 = v1 + `spstruct.py`,
