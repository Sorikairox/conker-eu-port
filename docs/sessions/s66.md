## Lessons
- Two "unexplainable" schedule differences (empty delay slot, late `addiu a0,sp,K`) were basic-block boundaries. A natural source form is an inner `{ decl; ... }` block, not a label.
- `li` of the same constant into a fresh register = a different C type of the destination.
- The spawner tail family (`func_15132FBC` callers) is now a recipe: named result declared first, no struct member for it.
