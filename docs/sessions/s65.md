## Lessons
- "Extra compiler temp" in a frame can be an **extra call argument** from a wrong m2c prototype: count the stack stores of the call against the frame.
- The permuter's `new_var = arg` is often a real source variable (a second pointer to the same object), and naming it can also explain a slot puzzle.
- Spawner initialisers: sort by field offset, use `u8` for `0xFF`-style fields, struct-copy the vec3s; then screen.
